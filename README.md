# TenantEase – Full‑Stack Property Management

## Overview
TenantEase is a modern property‑management platform built with:
- **Frontend:** React + Vite, Tailwind CSS, Zustand for state, React‑Hook‑Form + Zod for validation, lazy‑loaded routes, role‑based protected pages.
- **Backend:** Node.js + Express, TypeScript, JWT authentication, RBAC middleware, Prisma ORM.
- **Database:** Prisma schema ready for **PostgreSQL (Supabase)** and a local **SQLite** fallback for quick development.

## Quick Start (Local Development)
```bash
# Clone the repo
git clone https://github.com/rathoretina07/TenantEase.git
cd TenantEase

# Frontend
cd app
npm install
# Environment (frontend) – API URL points to the local backend
cp .env.example .env   # edit if needed (VITE_API_URL defaults to http://localhost:3000/api)
npm run dev   # runs on http://localhost:5174 (or next free port)

# Backend (SQLite – no external DB needed)
cd ../backend
npm install
cp .env.example .env   # already set for SQLite dev.db
npx prisma generate    # generate Prisma client
npx ts-node prisma/seed.ts   # seeds a manager, tenant, property, lease, payment
npm run dev   # starts API on http://localhost:3000
```
Log in with the seeded manager account:
- **Email:** `manager@tenantease.com`
- **Password:** `password123`

## Switching to Supabase (Production)
1. Create a Supabase project and enable **Connection Pooling**.
2. Copy the **Transaction** URL (ends with `pooler.supabase.com:6543/...`) and the **Session** URL.
3. Edit `backend/.env`:
   ```env
   DATABASE_URL="<TRANSACTION_URL>"
   DIRECT_URL="<SESSION_URL>"
   ```
4. Run the migration:
   ```bash
   npx prisma db push   # creates all tables on Supabase
   ```
5. Deploy the backend (e.g., Railway, Fly.io, Render, or a VPS) and set the same env vars.
